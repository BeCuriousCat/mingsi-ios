我做了一个训练自己把事情想清楚的 App

每天做了很多事，但经常没想清楚为什么要做。日记写过、Todo 建过、AI 聊过，但复盘写成了流水账，任务只管加不管验证，聊天聊完就散了。

后来我意识到：不是缺工具，是缺一个闭环。

所以我做了一个 App 叫「明思」。

它的核心逻辑是五步闭环：
1. 澄清：花几分钟输入今天的想法和判断
2. 质疑：AI 帮你拆成卡片，你确认或修正
3. 选择：AI 提出追问，你做出判断
4. 行动：生成明天可验证的任务
5. 校准：第二天回来验证判断对不对

重点：AI 不替你思考。它只负责把你的判断重新摆到你面前。

数据全在手机本地，不需要注册账号，不需要联网同步。用你自己的 API Key，数据不经过我的服务器。

目前 MVP 已经跑通，后续会加原则沉淀、项目追踪、自定义透镜。

如果你也是那种每天都在做事、但经常觉得没想清楚的人，可以看看这个思路对不对。
