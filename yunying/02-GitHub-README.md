# 明思 MingSi

个人思维训练与复盘 App。

---

## 为什么做这个 App

做了很多事，但没想清楚。

每天都在接收信息、做判断、推进任务。但大部分判断是模糊的、任务是没有验证的、复盘是草草了事的。日记写了几周就断了，Todo 列表越来越长但没人在意完成质量，AI 聊天聊完就忘了。

不是缺工具，是缺一个把事情想清楚的闭环。

明思的出发点很简单：每天花几分钟，把混乱的输入变成可确认的事实、问题、判断和任务。然后第二天回来验证。

---

## 核心闭环

```
Clarify → Challenge → Choose → Act → Calibrate
澄清    → 质疑     → 选择   → 行动 → 校准
```

- **Clarify**：用户输入今天发生的事、想法、困惑。不需要写成文章。
- **Challenge**：AI 将输入整理成思考卡片，用户确认或修正。透镜提供不同审视角度。
- **Choose**：AI 提出追问，用户做出判断。
- **Act**：从判断中生成明天的主线任务，包含完成标准和验证问题。
- **Calibrate**：第二天回看昨天的判断是否成立，校准自己的思考偏差。

---

## 当前 MVP 功能

- 今日复盘：语音或文字输入，低成本收集原始思考材料
- 思考卡片：AI 整理成事实、问题、决策、风险、想法、沟通、任务七类卡片
- 思考透镜：证据校验、反方视角、杠杆分析三种内置视角
- 深度追问：基于确认卡片提出引导性问题
- 明日任务：生成带完成标准的可验证任务
- 次日验证：回看昨日任务完成度和实际价值
- 历史证据：回溯复盘、卡片、任务、验证记录
- 本地存储：所有数据存储在设备本地，不经服务器

## 隐私原则

- 所有数据存储在设备本地。
- 不要求注册账号。
- 不收集用户行为数据。
- AI 调用仅在用户主动触发时发生，用户需要自行配置 API Key。
- 不向任何第三方服务器发送用户数据（除用户配置的 AI 服务外）。
- 未来若增加云同步，将以端到端加密为前提，且为可选功能。

---

## 技术栈

- **平台**：iOS（Swift / SwiftUI）
- **架构**：The Composable Architecture (TCA)
- **本地存储**：SwiftData
- **AI 服务**：支持兼容 OpenAI API 的服务（用户自行配置 API Key）
- **Keychain**：系统 Keychain 存储 API Key
- **构建**：XcodeGen 管理项目文件

## 安装与使用

1. 克隆仓库
2. 安装 XcodeGen（`brew install xcodegen`）
3. 运行 `xcodegen generate` 生成 Xcode 项目
4. 打开 `.xcodeproj`，选择模拟器或真机运行
5. 在 App 设置中配置你的 AI 服务 API Key
