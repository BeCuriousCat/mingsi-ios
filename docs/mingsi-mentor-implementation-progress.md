## 2026-09-11：F03 中断恢复与显式重试

v60 的 retry_of 保留请求重试链。submitTurn 显式带 retryOf 时，只接受同会话终态请求、相同意图/上下文/原话和未变化的语义修订；创建新请求 ID，复用已有 user_item_id。重复重试命令返回同一次 attempt，不重复插入用户文字。事实纠正后旧快照不允许直接重试，需由后续上下文服务重新组装新请求。

新增恢复幂等、草稿保留、旧回应拒绝、重试原话复用、新请求 ID、终态保护、输入变更/修订过期拒绝及整链删除测试。App 启动及网络服务尚未接入这些命令，不能据此声称实际断网/重启体验已验收。
