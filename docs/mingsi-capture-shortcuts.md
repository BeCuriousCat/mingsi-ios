# 一键打开今日闪念

安装明思后，可以把“打开今日闪念”单独放到iPhone主屏幕，之后点图标直接进入输入页。这个动作不需要配置模型；文字可以先留作本机草稿。

1. 打开系统的“快捷指令”App，在资料库中找到“明思”。
2. 长按“打开今日闪念”卡片，选择“添加到主屏幕”。
3. 保留或调整图标名称，点右上角“添加”。
4. 回到主屏幕，点“打开今日闪念”，即可进入明思的闪念编辑器。

另一个入口是长按主屏上的明思App图标，选择“记录闪念”。App内则从今日首页点“先记一条闪念”。输入框右下角的小麦克风用来开始语音，再点一次停止；识别文字可校对，确认后使用。实际麦克风与语音识别需要本人允许系统权限。

“记录到明思”是另一个快捷指令动作：接收已经有的文字并直接保存。想先打开输入框时，选择“打开今日闪念”。

找不到卡片时，先普通打开一次明思，再返回快捷指令检查。若卡片存在但执行报“无法运行App快捷指令”，保留错误和应用版本供诊断；不要通过卸载或清空数据来排错。
