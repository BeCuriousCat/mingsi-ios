# 明思：完整人生指南

版本：0.3；更新：2026-10-09

明思收录《高性价比人生指南》固定提交 `e73cb638b27f12a422546e5c09cadcac6fce03fe` 的 34 节、670 条建议、10 篇长文和 41 个术语。来源为 `eternity4719/HowToLiveBetter`，正文许可 CC BY 4.0。另保留 12 条明思改写建议。原条目保持真实的 draft 状态，收录和推荐资料入口不代表独立审核完成。

## 两种触达

1. 每日首次打开时，从全部完整资料条目和已审核改写建议中随机选择一条；保存正文快照，同一自然日内保持稳定。
2. 完成回顾后，由中央模型判断用户明确表达的事件是否与某条资料特别相似。先读全部候选标题，选至多 5 条，再读取完整摘要、成本、收益和备注核对。一次回顾最多出现一条入口，连续原话至少六字、置信度至少 0.9；没有充分对应就不推荐。空结果也保存，同一次回顾不会反复请求；同一条回顾推荐 14 天内不重复。

首页不增加“给我一条建议”按钮。两种触达都提供可选择打开的卡片。相同条目合并卡片，回顾来源在详情显示。原资料卡不会生成针对个人的医疗、法律或投资结论；保留原文数字、适用条件、证据与地区限制。收益与证据是来源陈述，不能当成对用户效果的承诺。

## 阅读与使用

- 完整指南可全文搜索，按章节、证据等级、收益和低成本筛选；长文、术语和项目说明可以在应用内阅读。
- 原文详情展示成本、收益、证据、备注、成本标签、原始 Markdown、来源和版本；长文使用原生标题、正文、表格阅读块，已收录文档的内部链接在应用内打开。
- “带入今日闪念”打开独立输入表单，预填完整原条目、出处、提交和许可；用户可以编辑后保存。此操作不修改今天已有的整理草稿或训练结果。
- “结合我的情况聊聊”将同一份材料预填到导师输入框，由用户补充和发送。
- 收藏、试过、实际观察和今天不适合使用统一数据库反馈记录，包含完整内容快照；重开、版本更新或当前指南移除后仍能回看旧正文，进入数据导出。实际观察可使用统一语音输入组件。
- 旧 UserDefaults 收藏仅在所有数据库快照保存成功后清除；保存失败保留旧收藏并显示错误。

## 数据与模型边界

`LifeGuidanceItem.referenceEntry` 保留原条目；没有该字段的旧记录仍可解码。明思改写建议仍要求 approved 与完整发布字段。原文入口使用单独的资格规则，不伪造 firstStep、观察信号或审核状态。

`life_guidance_exposures` 持久化每日/回顾决策，`life_guidance_feedback` 持久化反馈与完整快照。反馈写入成功才更新界面，并使预备导出失效。删除导师会话会清除关联回顾；迟到模型记录不能重新写入已删除会话。

`lifeGuidanceShortlist` 和 `lifeGuidanceReview` 均经中央决策中心执行并保留来源审计。输入事件最多 20 条、合计 8,000 字；每次请求最多 160,000 字节。超限不会截断候选或改用本地关键词判断。模型输出必须来自实际候选 ID 和用户连续原话。

## 验证范围

验证完整 670 条都有每日选择资格、全部标题参与回顾查找、原备注进入核对、draft 改写和虚构 ID 拒绝、14 天去重、保存失败、旧收藏迁移、数据导出和旧版本回看。

模拟器操作验证收藏→列表→重启回看，原文→完整预填→保存→重启闪念回看，大字号深色下记录观察并重开。Release 验证完整 JSON 入包与 draft 工作副本排除。模拟器不代替真机麦克风、Siri 和系统桌面快捷方式验收。
