## 当前实现回写（2026-10-14）

本文保留 2026-09-10 的设计基线。实现审视已完成一轮回写：正式教材包已创建并按用户授权记录 AI 编辑审核身份；导师回应 Prompt 当前为 2.7.0，理解草稿保持 2.6.0。回应 Prompt 从逐版叠加改为基于独立合同的一份当前多轮规则，明确新事实更新旧判断、每轮只做一步、普通交流默认收束，以及回看补材料问题预算不等于整个对话轮数；历史版本仍保留回放。导师回应有本地最低有用性质量门，拒绝明显无来源或空泛的新增输出。Today 追问 Prompt 当前为 1.24.0，移除历史 Prompt 拼接造成的题量和训练清单冲突，增加用户价值门槛，明确用户边界和回答优先，标准／深度模式都只生成当前轮 0 或 1 个问题；回答复盘未就绪时，下一条修补追问会变成可直接回答的新问题卡，并在同一训练目标内最多追加两轮；标准模型响应包已严格解包并支持重启回放；启动恢复失败有可见重试。固定 iPhone 17 上的全量技术回归和 3 条生产首页 UI 路径通过。

尚未证明的部分仍是模型语义质量、真实约 14 天使用、真机／VoiceOver 矩阵和长期生活改善。结构契约、模拟器夹具和教材数量不能替代这些证据。

## 2. 评审后落实的修正

| 发现的问题 | 最终设计 | 对应验证 |
| --- | --- | --- |
| 用讲解或比较附带问题绕过两轮限制 | 补材料问题按用途计数，所有主动作共享预算；保留语义误标风险 | X06、X16 |
| 有话题时切到听讲可能触发模型 | 静态阅读和换题始终本地选题；相关选择只附带于主动在线请求 | T01、X07 |
| 长会话只保留最初问题，丢掉后来纠正 | 旧材料与有效纠正一起保留或移除；不确定时由用户选择事实片段 | T05、X13 |
| 教学按钮可能被误当作用户理解 | 按钮仅保存意图；整理资格不能只依据存在 user 条目 | T10、X15 |
| 交流成功与保存、呈现事实混淆 | 事务提交后呈现，实际出现另作幂等确认；本地保存失败不重发网络 | T14、X01、X06 |
| 删除后审计、导出和旧备份仍能带回正文 | 明确请求所有权、迟到拒绝写入，以及应用管理副本的删除责任 | T16、X02、X12 |
