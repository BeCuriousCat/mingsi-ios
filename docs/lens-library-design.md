# 透镜：选择边界、能力目标与提示词

日期：2026-10-21。范围是 Today 的可选思考视角、请求上下文与对应选择页面。不是新增人格测评，也不把完成对话视作能力提升证明。

当前入口：首页向下滚动至「今日整理」→ 事项训练流程的「选择一个视角（可跳过）」。首页「听一个新视角」仍是教材入口，不是此透镜选择页。

透镜值得独立存在，需要同时满足：常见且可辨认的使用场景；能改变一次判断的独特思考动作；能用用户现有信息作答；可明确说明不适用条件。领域名、名人名或“更深入”本身不够。一次只做一个动作，解释适用条件，允许未知、拒绝和不行动。

## 本次目录：六个保留、四个新增

| 视角 | 有意义的触发 | 实际练习的能力 | 与其他视角的区别 |
| --- | --- | --- | --- |
| 证据校验 | 把推测说得比观察更确定 | 分清事实与解释 | 先检查依据，不要求寻找反方 |
| 反方视角 | 结论明确，只搜集支持理由 | 为判断设可被推翻的条件 | 对当前结论寻找替代解释或反证 |
| 杠杆分析 | 很忙却不改变关键结果 | 识别瓶颈与结果影响 | 比的是改变结果的环节，不是人生价值排序 |
| 第一性原理 | “只能这样”的规则来源不清 | 区分必要条件与沿用假设 | 审前提，不强求从零重建整个方案 |
| 系统思维 | 问题反复、延迟或依赖传导 | 看见回路与二阶后果 | 关系仍是待检验假说，单次事件不证明回路 |
| 判断校准 | 有原先预测与后续结果 | 按证据更新确信程度 | 不编造过去的把握，不用单次结果评价能力 |
| **机会成本** | 同一段时间/资源的真实取舍 | 看见放弃的备选与自身价值 | 休息和关系也有价值，不默认效率至上 |
| **可逆决策** | 不确定条件下是否作出承诺 | 识别退出成本与承诺边界 | 不把“试一下”默认说成安全，不必真的试验 |
| **换位理解** | 双方信息/目标/限制不同 | 准确表达另一方处境与已知诉求 | 理解不等于认同；不读心，也不替伤害辩护 |
| **可控边界** | 为他人反应和外部结果反复耗能 | 分清决定权、影响力与外部条件 | 不归咎个人，不把结构限制解释成态度问题 |

这四种新增角度也分别复用现有的取舍、约束分解、替代解释动作；共享动作不等于共享目的。它们的对象分别是被放弃的价值、承诺的退出成本、另一方的已知处境和自身决定权。没有增加抽象评分维度，历史 id 与 JSON reasoning move 保持兼容。

## 经过考虑但本轮不单列

| 候选 | 决定与原因 |
| --- | --- |
| 概率/基准率/幸存者偏差 | 作为证据与判断校准的具体用法；若缺可比样本，不虚构概率。未来有明确频率估计交互时再独立 |
| 预演失败/逆向思考 | 归入反方视角；不能只是换名，也不能给疲惫用户追加灾难清单 |
| 时间尺度/长期主义/二阶效应 | 归入系统思维的延迟与后果；长期并非总优于短期 |
| 沉没成本 | 机会成本的一个适用情境；已付成本与未来取舍要分开 |
| 情绪觉察 | 情绪是有意义的自述，不能当成错误或心理诊断；目前先作为所有透镜的材料边界 |
| 习惯/执行力/成长型思维 | 不能由一件事诊断用户缺什么；自愿行动时作为建议工具，不强制设训练课 |
| 职业/健康/金钱/亲密关系 | 这是生活主题，不是独立思考方法；高风险领域需要专业边界 |
| SWOT/六顶帽/名人思维 | 容易变成表单和标签堆积；已有的一步式能力足够时不新增入口 |

## 提示词结构

每个方法资产有独立 purpose、promptGuidance、questionStrategy、applicability、disableConditions 与可选行动规则，随 `lensCatalog` 进入模型上下文。当前目录为 builtin.v3；旧存储 id 不变，无数据库迁移。换位理解改为准确表述双方已知诉求与限制，避免反复退回证据核对。历史 v2 上下文保留原版本，初始推荐 1.2.0 的 v2 目录已完整冻结。初始模型也读取十种方法的目的、条件和边界，不能只认识新名字。

1. 先读当前目标、已确认材料、用户边界；视角不能充当证据或缺陷诊断。
2. 看是否确有一个能改变判断的区别。如果有，只问现有信息能回答的一处；如果没有，允许不问。
3. 问题说明当前推断、实际意义和可能更新的判断，不能在解释里藏第二个任务。
4. “答到哪里”允许不知道原因，不把继续使用或完成反思绑定到调查、试验、谈话和明日作业。
5. 行动只在用户希望时考虑；停止、休息、寻求帮助或不行动都是有效选择。
6. 变化证据来自具体自述：之前怎么判断，新材料改变哪一处。完成、好评和结果好不自动证明能力提升。

`generateQuestions` 当前 1.29.0，回退 1.28.0；在零或一个问题的价值门上，进一步允许真实取舍、个人价值及双方已知侧重点成为有用材料，不要求它们都有事实缺口。没有事实缺失时使用 none，不编造好意动机，也不反复要求用户证明已承认未知的意图。`diagnoseTrainingCase` 当前 1.3.0 读取 v3 目录，回退 1.2.0 的完整冻结 v2 目录。输出 schema 分别为 7 和 2。用户要求直接讲解时，返回有来源的解释而非空白问题页，允许保存并结束；说明随事项保存/恢复，不是用户事实或能力增长证据。

## 回答后的承接

`reviewCoachAnswer` 1.5.0 进一步将证据状态、追问价值和行动意愿分开：理解了区别并不证明原因已确定；仍有未知也不强制再问。需要讲解时先给具体解释，空训练字段保持为空。用户可保存返回，再明确选择是否设计验证。实现、基线失败与验收证据见[回答复盘报告](qa/2026-10-21-answer-choice/README.md)。 后续已修正取消/失败重试误入问题生成、无透镜不能重试及保存后上轮上下文丢失；缺初始判断时也可直接复盘当前回答。见[交互恢复报告](qa/2026-10-21-review-retry/README.md)。

## 界面修正原则

以当前 DESIGN.md 的 18pt 页边距、14pt 内容内边距、10pt 常用圆角和 44pt 点击目标为准。对称是同级容器两侧留白和控件规则一致，不是把长正文居中，也不是强迫不同文案同高。

选择页按“看清事实与解释 / 比较选择与代价 / 重看前提与边界”分组，单列选项完整换行，用文本和选中符号表达状态；不再用两列固定高度截断标题。选择与说明入口是独立控件，说明入口至少 44pt。详情解释目的、条件、一个示例问题和边界，选中不会自动请求模型。创建自定义方法收进次级展开区，避免先要求用户创造方法才能选。

推荐卡移除不对称的粗左色条，多行思考方向从胶囊换成可换行矩形标签；最大辅助字号下推荐操作改纵向排列并保持点击高度。首页入口明确左对齐、多行文本和纵向留白。

选择行按实际文本计算完整高度，装饰图标保持紧凑，说明按钮保留 44pt 目标；改选不隐式动画重排行高。说明模态明确承接当前字号。浅色与深色主按钮均使用 `DS.onAccent`，避免深色浅绿底上继续使用白字；配色计算与实际截图分开验收。

验收要分别看：本地回归、真实页面、实际模型响应。测试通过不等于语义有效，合成夹具不等于个人真实效果。当前结果与限制在专项 QA 报告记录。

参考规范：[Apple HIG Layout](https://developer.apple.com/design/human-interface-guidelines/layout) 关于阅读顺序、对齐、分组、渐进披露、字号变化与安全区的原文已复核；具体间距仍采用本项目 DESIGN.md。规范不是要求所有内容居中或机械镜像。

## 辅助提示不打断透镜思考

`recommendGuidance` 1.1.0 同步读取当前问答、已有讲解与复盘停止边界。缺少 fact 卡片只是候选检索信号，不能把价值取舍或一般讲解重新压成“补事实”；已经解释、用户想停下或只是增加任务时不提示。相同材料成功 show/hold 进程内复用，页面出现才计冷却。两个真实新场景已分别得到合适的 hold/show 并逐条 AI 审读，页面普通/最大字号展开关闭也已验证；范围和失败见[辅助提示验收](qa/2026-10-21-guidance-presentation/README.md)。没有把这些有限结果称为长期能力提升。


## 长材料下的理解边界

老师回应也能作为用户主动选中的解释上下文；正文和问题分开选择，可先展开全文。新输入需要至少选一段，防止历史片段取代本轮诉求。`mentorRespond` 2.16.0 保留完整 2.15.0 回退，不从省略内容推断用户经历或同意；只有实际收到的片段可用于解释。详见[专项验收](qa/2026-10-21-context-selection/README.md)。本项不改变 Today 十种透镜目录与问题生成版本。
