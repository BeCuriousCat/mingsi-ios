## 改动

删除本地计分、固定增减分贡献、加总和理由/总结函数，以及恢复/完成记录时对它们的调用。保存结果、选择透镜、完成流程不再自动创建成长分数；保留事项归属上下文，供用户主动生成报告时使用。不足三次时服务仍不请求模型，只返回无分数/无贡献状态；不把数量不足写成能力不足，也不分配练习换分数。

旧作者固定摘要“已基于 N 次完整复盘生成本地成长快照：P 条正向证据，Q 条负向证据。”作为兼容识别签名。匹配的原始快照不可显示分数；读取只构造中性说明副本，不改原行的状态、数字、时间或贡献。历史贡献在 SQLite 内按 snapshotId 排除此类作者，再做同来源版本去重，避免较新的自动汇总盖住较早的报告；指标明细和下一次报告的数值基线同样排除。未知历史来源不重新分类，此签名检查不代表独立作者认证或完整历史审计。

成长空状态移除三点达标进度，显示当前已读取记录中的完整复盘数量及真实报告说明；数量来自 HistoryRecord，报告的 completeLoopCount 不被改成全局计数。“回到今日”在零条、三条及旧汇总状态均可用；结果未知不要求追加练习获得成长分。保留原有暖色、原生字体及浅/深色设计。报告生成、指标复核和历史原始记录入口继续沿用原有路径。

本轮没有修改 weeklyCalibration/monthlyGrowth 的 Prompt 文本或版本，未发新外部模型请求。服务的空状态说明、旧数值基线过滤以及客户端展示变化由本地验证承担；不把之前模型样本重新计为本轮实际调用。
