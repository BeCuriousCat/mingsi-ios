## 当前实现

verifyQuest 升为 1.11.0 / schema 5，精确保留 1.10.0 回退；模型收到原则触发场景、动作、成功标准和例外，返回独立原则行为评估：做过、部分做过、明确没做或无法判断。必须根据当前原文，不从选择、自评、计划、好结果或其他评语推断；用户不记得过程应保持无法判断，不要求补练习获得标签。做过动作可以与失败或未知结果同时成立，不证明因果效果、能力或内化。

服务校验原则身份、有效行为上下文和一至三段连续原文引用；未知状态必须空引用。引用字面归属仅证明来源，不保证语义正确。AppStore 使用已保存 Verification 原文及评估，只有匹配、有效原则及做过/部分做过时生成 schema 2 派生记录，不再使用关键词或结果出现作为替代条件。派生记录使用 Verification ID，同一来源/行动去重；旧自动关联保留，不能阻止新的有效行为报告。

v74 仅增加可空评估列，旧行保持 nil；独立仓储和验证/行动/回执事务均保留评估，历史上下文可读取。原则列表在保存后刷新。旧自动关联不计为实践，提示缺少行为记录；提醒有帮助单独计数，不转换成实践。三次报告不会自动内化，只有明确手工自报才显示“自报已形成习惯”。展开原文不再限一行，用户可否认归属，历史待核对提示继续保留。
