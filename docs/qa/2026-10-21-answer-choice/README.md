# 回答复盘：未知、追问与行动选择

日期：2026-10-21。承接[透镜扩充](../2026-10-21-lens-library/README.md)。新方法的价值需要体现在实际回应中，不能只扩充菜单；本轮处理回答后被强制继续答题或设计行动的问题。

## 改动与证据边界

`reviewCoachAnswer` 1.5.0 / schema 1，保留原 1.4.0 及更早历史模板。分开三件事：材料是否支持验证、是否还有可回答且有帮助的问题、用户是否愿意设计行动。明确要解释时，先用当前事实解释推断差在哪里。原因未知可以保持未就绪，也可以没有新问题；不把空问题解释成用户拒绝继续或原因已确定。

解析器仍保留真实来源、单一缺口、就绪不得追问、停止不得转移安排练习等边界。新增澄清动作必须带实际问题的检查。删除对空训练目标、自检、输出、经验比较和已补材料的本地补写，空参考例子也不再变成新的写作要求。界面只在有实际可选指导时提供展开，不显示空条目。

生产 Today 的复盘结果无待答追问时，主动作改为“先保存，返回今日”；有追问时提供同名的次要出口。已有可验证判断时，用户可另选“另行设计一个验证行动”。保存保留当前回答、透镜选择、真实准备度和缺口，不把现实事项标为完成。使用现有持久化返回路径，新增防重复提交状态；写入失败保持原页面。
