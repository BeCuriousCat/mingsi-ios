# 原则候选确认与保存 · 2026-10-18

## 问题与修复

审查发现原则生成、候选编辑都会调用 `savePrinciples`：候选默认 active，会在确认前进入正式原则库。跳过又用空数组替换当天资产；同日其他事项的原则可能被软删除。完成状态在异步写入结果前显示，失败也可能离开。

现生成与编辑只保存按事项隔离的候选草稿，明确选择“保存为我的原则”才逐项保存资产；跳过仅移除当前草稿键，保留当天其他资产。候选不进入原则召回、历史或成长证据；去重也只使用已确认资产。切换事项及重启恢复草稿，迟到的生成结果校验日记录及事项归属。编辑自动同步草稿，直接点击确认保存最新文字；空标题、摘要或动作无法确认。原则卡展开行动步骤、成功标准和例外条件，“完成编辑”与最终确认分开。

保存/跳过共用保存锁，写入成功后才显示完成、返回事项；失败保留页面及候选，按原 ID 重试。`v72_principle_review_drafts` 添加可空草稿 JSON，旧记录读取空字典，不补造旧确认事件。历史库没有足够信息区分过去自动写入与明确确认的资产，本轮没有自动重分类或删除旧资产。

首次专项 674 通过、2 失败：[摘要](evidence/focused-initial-summary.json)。失败来自只含部分表的旧迁移夹具；新增迁移现对缺表/已有列采用与既有迁移一致的保护。最终专项 679 通过、0 失败、0 跳过：[摘要](evidence/focused-final-summary.json)。覆盖真实 SQLite 迁移/草稿往返、同日资产保留、生成候选、事项切换和新 Store 恢复，以及资产/会话/事项/日记录写入故障和重试。

完整单元 1384 通过、0 失败、6 个显式 opt-in 跳过，见[摘要](evidence/unit-summary.json)。两条实际页面 UI 通过、0 失败、0 跳过，见[摘要](evidence/ui-summary.json)：主动进入后跳过能完成且无本次沉淀；候选完整边界可查看，编辑中直接确认保存最新文字。已人工查看[正常字号深色截图](evidence/screenshots/85A85ABD-5526-46BC-A5E0-09C30B3FCAC5.png)。UI 为显式隔离夹具，不读真实用户数据或 Keychain；本轮未新增最大字号、浅色或真机验收。补查确实复现跨事项迟到错误：旧请求失败后会把新事项从 selectLens 改到 extractPrinciple，并覆盖提示，见[反例](evidence/late-error-before-summary.json)。现请求前上下文读取、成功与失败都验证日记录及事项归属。加入该修复后的完整单元 1385 通过、0 失败、6 个显式 opt-in 跳过，见[最终完整摘要](evidence/unit-final-summary.json)。之后补充跳过会取消进行中的原则重试，成功完成清理重试状态，避免旧请求重新打开已结束流程；最终七条相关检查全部通过、0 失败、0 跳过，见[摘要](evidence/close-summary.json)，覆盖取消中的跳过、跨事项迟到错误、故障重试、旧原则保留及保存/跳过的完成路径。UI 验收早于最后的非 UI 请求归属和取消补差，没有把先前 UI 声称为完整代码的全部分支验收。本轮未修改 Prompt 或额外调用外部模型；上一轮真实 Prompt 输出的限定结论继续适用，不因保存修复宣称语义效果提升。

## 限制与后续

仓储仍分次写入。用户明确确认后，资产写入可能成功而完成状态失败，当前页会保留并可同 ID 重试；未证明跨仓储崩溃一致性。草稿读写和 UI 夹具不代表真机或真实个人日常验收。结果校准有观察/冲突样本的真实模型验证、长文案负担及整体 App 验收仍未完成。
