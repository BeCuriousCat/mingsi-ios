# 总 Goal · M0 需求与证据台账

日期：2026-10-23。契约：[长期 Goal G1–G10](../../mingsi-long-term-goal.md)。

上一目标回合完成了契约、实际 Goal 设置和公开文档同步，属于进展。本轮开始补证据缺口与数据恢复能力，不重跑付费模型来凑指标。

状态定义：**部分**表示已有范围有限或历史版本证据；**未测**表示缺少符合当前门槛的证据；**通过**仅用于同一候选版本、规定范围内可核查的验收。没有将表内历史资料改记为当前版本全量通过。以下链接已在本轮阅读，历史细节以各报告保留的失败与边界为准。

## 本轮优先问题

1. P0/G1：闪念正文与待确认转写只在视图内存，App进程终止后丢失；正文没有自动草稿恢复。
2. P0/G1：共享语音组件退后台直接discard，用户还未确认的识别文字会消失。
3. P1/G1：正式闪念保存与草稿清除需要原子提交，不能重启后重复保存，也不能草稿先清后保存失败。
4. P1/G2/G8：保留、明确丢弃、存储失败重试应可辨认；待确认识别不自动算正文或触发交流。

处理与运行证据见[本轮草稿恢复报告](../2026-10-23-capture-draft/README.md)。真实麦克风、真机和VoiceOver仍需实际设备操作，不能由这些修复自动关闭。

后续P07补证据：实际系统主屏菜单暴露暖启动只回设置的缺陷，已补场景回调并验证草稿不变、普通重启不误开。最终完整单元1517通过/24显式跳过/0失败，两条实际启动UI通过。见[快捷入口专项](../2026-10-23-capture-shortcut/README.md)。这不关闭真机P07，也不代表AppIntents/Siri或任意弹窗场景已验证。

试用工具补齐：[离线汇总](../../mingsi-trial-summary.md)可整理本机导出的已观测分母与状态；16项新增Python测试及合成CLI样例通过，未读取真人数据。G2/G4/G5/G6/G7/G8的真人证据状态不变，G3完整HTTP窗口也不由此成立。

G1/G3传输补缺：普通Chat流EOF和HTTP200内错误原先可误报完成，修改前3项基线全部失败；已修复并为Responses失败保留固定原因分类，未知不猜、诊断原文不展示、已知额度问题不自动重试。最终1524项单元通过/24显式跳过/0失败；[专项证据](../2026-10-23-stream-failure/README.md)。没有实际供应商调用，原3次未知服务失败不回填原因，G3真实网络UI与50请求窗口仍未完成。
