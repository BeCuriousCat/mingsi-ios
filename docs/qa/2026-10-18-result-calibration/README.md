# 结果回顾：模型判断、用户自评与保存链路 · 2026-10-18

明思的主要风险继续表现为“流程记录被当成实际学习”：Prompt 能给出有边界的反馈，客户端却丢掉结构化评估，只把用户选的“确认判断”显示为“判断更新”，并统一提示形成成长证据。这会使模型对反例或不确定性的提醒在产品中消失。本轮修复结果保存到回看的链路，整体目标仍在推进。

## 真实模型检验

复用用户已授权的 CC Switch 当前伊莉丝 Responses 连接，仅固定 iPhone 17 / iOS 26.5。三条合成材料都故意选择 done/high/confirmed，要求结果判断服从实际记录，而非正面自评。verifyQuest 维持 1.10.0 / schema 4，没有为存储及展示改动重新调用模型。

| 场景 | 实际响应 | Codex AI 逐条复核 |
| --- | --- | --- |
| 添加字段示例后，朋友独立完成并解释字段含义 | observed / met / supported | 本次支持限于这个人这一次，保留熟悉度与推广限制 |
| 网络正常、设计不变，同一朋友仍留空字段退出 | observed / not_met / weakened | 重试动作完成不代表填写标准达成；削弱网络是唯一障碍，未确定另一唯一原因 |
| 同次操作的两份记录相反，来源时间未核实 | conflicting / not_assessable / unresolved | 不任择一份记录，不以完成/高价值自评消除冲突，也不从提交推断独立完成 |

三次实际回应，一条 opt-in 测试通过、零失败/跳过，见[执行摘要](evidence/live-summary.json)、[Codex AI 语义复核](evidence/live/semantic-review.json)及[请求和响应清单](evidence/live/manifest.json)。附件是生产适配器归一信封及助手正文，未保存原始线上 SSE；不是稳定成功率、独立事实核查或真机验收。支持样本正文仍偏长且出现内部值 confirmed，文案改善仍有空间。

## 修复内容

- CalibrationAssessment 进入领域模型，Verification 与 GrowthSettlement 保留独立模型评估、原文反馈和可选建议。judgmentUpdate 继续保存用户选择，不被模型覆写。
- v73 为验证和回执增加可空字段，生产验证/行动状态/回执通过既有事务保存；旧数据保持 nil，不补造历史 AI 结论。
- 今日回执改为“本次结果回顾”，默认展示证据判断及验收边界；原判断、结果和“你的判断自评”可展开。引用可展开查看，关闭只收起当前回执。
- 历史事项、历史验证和成长前后对照同样区分评估与自评。旧回执只展示实际保存的内容，不宣称有结构化判断。成长行本身是历史入口，行内不嵌套引用展开按钮。
- 保存成功改为“结果回顾已保存”，不统一宣称已形成成长证据。新评估为缺少观察或冲突时，不自动写原则练习证据，也不请求提示掌握/反例归属。旧 nil 评估保留兼容行为。

保留开发中问题：首次构建因新增测试缺 await 和初始化参数次序错误失败；修正后专项 351 通过、1 失败。失败夹具遗漏可选建议、原则练习审计反馈等当前契约字段，并有过短反馈，触发测试/预览允许的本地兼容回退；不是生产模型已调用成功的证据。补齐有效夹具后相关流程[独立复验通过](evidence/focused-close-summary.json)，再完整回归通过。没有削弱生产模型门。

两条页面 UI 通过、零失败/跳过，见[最终摘要](evidence/ui-summary.json)，`/tmp/mingsi-result-calibration-ui-final-20261018.xcresult`。实际执行反例/冲突正常字号与无结果最大辅助字号，展开原判断/结果/自评、反例引用以及关闭回执；旧历史回执仍显示原判断/实际结果和明确自评。截图见[清单](evidence/ui/manifest.json)，三张均已由 Codex AI 视觉检查。正常字号回执完整可见；最大字号虽可滚动操作，继承的页头占据大量空间，不能据此称整页阅读负担已通过。未验证 VoiceOver。

首次页面验收为一条历史通过、一条回执失败，见[保留摘要](evidence/ui-initial-summary.json)：父容器标识覆盖内部展开/关闭按钮，自动化无法定位；实际首屏回执也被其他内容推至下方。现移除父级标识、保留具体控制标识，将最新回顾置于今日内容前部，隔离夹具补齐内存建议仓储，避免测试显示仓储缺失错误；最终重跑包含以上修正。完整单元早于这些纯 UI/DEBUG 夹具调整，最终 UI 构建包含它们。没有借两条 UI 测试宣称全 App 回归。
