# 从自动缺口诊断改为复盘主题回看 · 2026-10-18

上一轮真实页面检查发现三条通用记录被标成“讲不清 · 沟通力”，并要求重写叙述。当前代码确认：CoachPatternSummaryPolicy 拼合原文、确认卡片、AI 问题/行动和结果反馈，每条强制分配一个本地缺口，按类型计数。没有材料缺口的中性记录也落入叙述 fallback；同样的摘要还通过 generateQuests 上下文要求按能力安排训练。AI 自己写出的提问/建议因此可能被当作用户能力证据。

修改前两条回归均实际失败，0 通过、2 失败，见[摘要](evidence/before-summary.json)，`/tmp/mingsi-pattern-before-20261018.xcresult`。一条确认三条通用原文会自动产生沟通缺口；一条确认手工传入的旧摘要会进入行动请求。这是生产判断来源问题，不是单纯改标签。

## 实现

停用原本地缺口摘要作者，保留旧 Codable 类型供历史解码；所有生产 Prompt 均不再接收旧摘要或其训练指令，AppStore 也不再生成。新 ReflectionTopicSummaryPolicy 仅索引实际保存且已回答的问题标签，不分析原文或 AI 建议来诊断能力。只回看最新 14 条已完成日记录（排除当前记录），主题至少跨两条独立日记录才显示，最多两项；相同记录或问题 ID 不重复计数，同一天同一主题最多一项。

问题和回答须非空、有明确问题类型，并能逐字回链同事项已确认、未排除卡片标题。vNext 优先本事项独立 reflectionState；即使其问题为空也不复活旧透镜副本。仅缺失独立状态时考虑同日同事项 LensSession；有多事项时不读顶层混合副本。无事项旧记录只接纳未归属事项的 LensSession / 卡片。不识别不完整来源，不回填旧标签，不新增迁移或持久写入。题目标签只说明当时讨论过，不证明尚未解决、相同原因、实践或能力。

成长页替换为“复盘中讨论过”：展开主题直接看到当时问题、用户回答和每条来源入口，保留不确定性；不再显示能力标签、缺口次数或自动练习。入口跳到对应日期/事项的历史。没有可用对照材料时说明仍可在历史回看原文。

行动 Prompt 升为 generateQuests 1.11.0 / schema 3，保留完整 1.10.0 文本回放/回退，追加历史主题边界：讨论过不等于用户缺陷，AI 问题/建议不等于用户行为，只按当前材料、最新回答和自愿边界选择单行动。新主题索引不自动传给模型。

## 限制

这是已有问题与回答的回看索引，问题标签本身仍可能是模型曾经的错误分类；未建立跨事件共同原因或独立能力评估，也不宣称改善长期思考效果。现有本地 Today 观察/训练处方还有其他使用路径，不将停用历史画像扩大宣称为全部本地指导已清理。未知历史来源、VoiceOver、真实手机、长期日常效果和报告原子持久化仍未完成，整体目标保持 active。
