## 代码中的竞态与修复

`persistSingleNudge`把草稿快照加入`persistenceChain`；`saveSingleNudgeNow`原先直接调用同一个repository写入，两条写入路径没有共享排序。数据库单次事务串行只能保证单次写入完整，无法保证排队的旧草稿一定早于新的生成结果写入。因此晚到的旧快照可以将问题和来源ID覆盖为空。

修复让立即保存也进入同一链，并等待该次写入的真实成功/失败。通用排队方法返回布尔任务结果，原有不等待的调用仍按顺序执行；保存错误提示与输入保留继续生效。没有修改数据库结构、已存记录或原问题断言。

保存可能等待其他写入，因此模型调用前再核对取消状态、请求token与当前会话。取消或切换后不发送旧请求；模型返回后的原有迟到隔离仍保留。首问、回答整理与继续点拨均应用调用前检查。
