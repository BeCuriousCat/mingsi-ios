## 实现与限制

- 派发时从实际客户端配置计算`cfg1_`版本化SHA-256：协议、实际端点、请求模型名、温度、空闲期限及JSON格式开关。Key不参与计算，原始地址和模型名不进入该观测字段；含URL用户信息、查询或片段以及非有限数值时保持未知。摘要是可关联的元数据，不声称匿名。
- 指纹随不可变attempt身份进入本机表。v79只追加nullable列，旧行不回填；重复登记或迟到指标不能为原attempt更换配置。删除仍级联，回调不创建记录。输出上限沿用独立字段，汇总时同时分组。
- 对账输出升级为v2，不同指纹分开时点分布；配置缺失或同窗多配置显示停止核对信号，未知配置不生成同服务延迟分位数。仍保留真实交易计数、失败和用量；此信号不是发送授权或生产配额。
- 同一指纹不能证明同一Key/账户、实际模型或后端执行预算。构建、Prompt、内容与账户仍需预登记；服务自报返回model与独立持久化写失败诊断仍缺。
