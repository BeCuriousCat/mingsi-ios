# 今日回顾停止边界与反馈负担 · 2026-10-17

本轮继续审视思考与引导链路，发现最大问题的一处具体表现：模型已经停止，客户端仍补出练习，界面与主按钮又继续要求训练。Prompt 单独通过不能证明用户真正得到收束。

## 证据与修复

前一轮真实 Today 输出将 experience_replay_prompt、judgment_sentence_prompt 等置空；但生产解析器用 fallback 生成“比较旧经验”“把判断写完整”，随后页面显示“想想以前类似情况”。新增两条反例在修复前失败，见 `/tmp/mingsi-stop-contract-before-20261017.xcresult`。不能继续把之前原始输出语义合格当作整个呈现合格。

当前回答复盘 Prompt 升为 1.4.0，1.3.0 原文保留可回放。要求回应短小、只处理一个缺口，可选练习默认为空；用户停止时四个其他练习/参考字段也必须为空。客户端拒绝 stop 携带旁路练习，保留有意的空字符串，并将停止状态传给页面；既有历史反馈缺少 boundary 时可解码，不推断用户已停止。

默认反馈去除重复的“需要补充”和旧经验训练，保留一次回应及一个必要问题/下一步；训练细节由用户展开。停止后不显示训练工具和诊断路线，固定主按钮为“先到这里，返回今日”；后续验证仍需用户主动选择，不把停止当作 ready。

同时发现未选透镜的回答只存内存，返回后会丢失。v71 新增本事项独立快照，保留问题/回答、复盘反馈和停止状态；编辑后清除陈旧反馈。返回与切换在持久化失败时保留当前页，允许重试。旧记录新增列为空，不补造历史复盘。

完整套件的五项跳过为需显式启用的外部模型/导入测试，本轮真实 Today 另行执行通过；导师与连接导入的独立通过记录见 [CC Switch 报告](../2026-10-17-cc-switch-compatibility/README.md)。最终以无夹具参数重新启动正常 App 成功；`git diff --check` 通过。当前任务文件未检出所用密钥字面值，构建目录无遗留临时凭据 xctestrun。未发布安装包。
