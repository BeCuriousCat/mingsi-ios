# 中性结果输入与可靠提交 · 2026-10-18

结果回顾仍在引导用户为已选判断寻找支持：提示要求“写下一条支持这个选择的真实结果”，且判断只有确认、调整、推翻，没有暂不能判断。保存方法也没有同步防重入锁，等待模型后直接修改当前页面。修复前两个实际回归均失败：重复点击未锁定输入；更换草稿后，旧请求仍保存结果并把新页面切成 Capture。见[反例摘要](evidence/before-summary.json)。这些缺陷继续支持当前主要问题判断：产品流程和自评容易压过实际观察与用户意愿。

## 本轮行为

先展示行动、原判断和原验收标准，再收集实际结果；没有观察、反例或记录冲突均可写。随后填写完成、价值和判断自评，新增“暂不能判断”并真实存为 unresolved，不把它变成模型结论。选项使用适配字号的网格，选中状态使用已有 onAccent 色和选中无障碍特征，触控高度至少 44pt。

提交锁在创建任务前设置，防止双击、编辑、重置和公共事项切换。模型阶段显示正在回顾，可取消；取消后释放前台模型占用并保留原文，新请求不会被旧请求的清理逻辑关闭。模型不响应取消、仍迟到返回时，也不保存旧结果。写入开始后不可取消；原事务可以完成，但归属不一致时不更新新页面、提示或回执。

存储失败会保留准备好的 Verification / GrowthSettlement 和相同 ID；相同输入重试只重存，不再请求模型。变更输入则重新回顾。使用真实 SQLite 加“提交成功后抛出确认错误”的夹具验证重试没有重复结果或回执；这是进程内恢复，不代表崩溃或重启后仍有此缓存。读取原行动来源失败会在模型调用前停止，不以今日 ID 替代原来源。

结果和回执写入成功后才完成事项状态；历史到期行动从仓储更新原事项，不要求其出现在今日内存列表。可选指导归属离开前台保存关键路径，失败不改写当前页面提示；它仍是现有的异步归属请求，本轮没有证明它的语义准确性、去重或长期生命周期。
