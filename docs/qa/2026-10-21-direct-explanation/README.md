# 透镜流程：直接讲解的返回、展示与保存

日期：2026-10-21。延续[透镜设计](../../lens-library-design.md)和[透镜区分验收](../2026-10-21-lens-distinction/README.md)。本轮修复初始思考阶段的真实缺口：旧提示词遇到“请直接解释”要求返回空问题，协议和页面却没有讲解位置，用户只能读到“没有追加问题”。

## 产品行为

`generateQuestions` 当前为 **1.29.0 / schema 7**，冻结 1.28.0 / schema 6 回退。模型根据实际请求和当前确认材料决定：需要互动时零或一个有用问题；需要直接帮助时零问题加简短讲解；用户停止或没有有用内容时允许二者都为空。没有本地关键词路由。

讲解说明一个具体区别、取舍或机制，保留已知与未知；不编造动机、不替用户排序、不暗藏问题或作业，也不声称完成对话证明能力提升。讲解页直接展示正文、AI 身份及当前卡片来源，主按钮支持保存并返回。保存再打开保留讲解，回到选择步骤不会因空问题而重复生成；更换事项、修改上游或重置问题会清空旧解释。

`CoachQuestionTurn` 补齐响应，保留既有问题列表 API；`CoachReflectionState.explanation` 是兼容旧 JSON 的可选字段，无数据库迁移。解析拒绝错误结构、空白正文、空来源和夹带问题的讲解，服务拒绝非本次确认卡片来源。输出指纹包括讲解正文与来源，nil 继续使用旧问题指纹。原有取消、迟到响应和事项身份检查保留。
