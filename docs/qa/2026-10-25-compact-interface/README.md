## 请求上限的准确含义

“原三次请求额度已用完”指原批次登记的3次生成动作：历史N01、意外确认消息、N02。它不是订阅余额、API服务配额或明思的每日使用限制；实际余额未查询。N03未执行。本页全部视觉操作和夹具不增加模型请求，不代表以后永久禁用模型。真实SSE增长、取消、真机麦克风、VoiceOver、真人价值和长期G1–G10仍按原门槛分别验收。
