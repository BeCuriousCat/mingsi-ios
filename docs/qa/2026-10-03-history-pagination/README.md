# 最近与全部交流混合分页验收 · 2026-10-03

## 用户结果与设计依据

对应 F13 / F14 / F17、FR-07、T15 / T17 的历史找回与旧点拨兼容部分。修正新交流与未包装旧点拨混排时可能跳过记录、重复取前面的旧根、旧点拨单独存在时无法加载下一页、超过 100 条旧根后请求非法页大小的问题。

每页继续展示最多 20 条，按活动时间降序、同时间按 ID 降序排列。新记录和旧根分别保留精确数据库游标，未展示条目保留在各自缓冲中；只有完整一页读取成功才提交游标和可见列表，失败后保留之前内容，重试不会越过失败页。刷新从头重读已加载页数，供详情返回、删除及旧根转为包装后恢复附近位置。

首页最近三条与全部列表共用分页规则，但拥有独立状态。首页继续入口分别查询两类资料的最近未结束记录，再按相同排序选取最近的一条；较新的已结束记录不会把它挤出入口。

旧根的列表查询仅提取 80 字预览、活动时间和生命周期，不读取整链、PromptRun 或理解正文。完整旧链及其来源仍在用户打开详情时读取；损坏 lineage 的原文继续可达，已有 Mentor 包装的旧根只保留包装条目。

同时同步 `project.yml` 的麦克风／识别用途说明，与当前 Xcode 工程已使用的“点按麦克风”文案一致，避免工程重新生成后恢复过时的“按住说话”。

## 边界

分页针对实时记录，不是冻结快照。记录在加载期间更新活动时间或转成包装后可能移到既有游标之前；返回详情或删除后刷新已加载范围。不会为固定排序创建历史数据副本。

本轮没有数据库迁移、真实旧用户库演练、全量 UI 套件、Release 构建或安装包发布。正式教材审核、真实模型语义与约 14 天试用、真机及辅助功能矩阵、整体 F19 / M1 验收仍未完成。
