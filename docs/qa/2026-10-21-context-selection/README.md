# 长材料的显式选择与连续理解 · 2026-10-21

这是透镜/导师提示词与相关界面的后续修正：长对话超过预算时，用户能够看清实际发送的片段，也能主动带入需要解释的老师原文。本轮不增加透镜数量；十种透镜的选择理由、能力动作和适用边界见[设计记录](../../lens-library-design.md)。

## 问题与改动

修改前两条回归 **0 通过 / 2 失败**，见[基线](evidence/baseline-summary.json)。只选历史原话会把旧材料误标成本轮诉求；选择候选没有老师正文，短指代缺失所需上下文。

- 有新输入时必须选入其一个片段，历史或老师片段不能代替当前请求；校验失败不发送模型请求。
- 老师正文与提问分别选择，只复制选中字段，不附带原用户原话、未选提问、内部引用或问题元数据。每个片段验证真实来源、字段与原文子串，拒绝伪造。
- 显式选择保留所有选中交流组，不再被六组窗口静默裁掉；仍超限就重新选择。未选相邻回应不会让更早老师回应被标为紧邻本轮。
- Prompt 2.16.0 完整保留 2.15.0 回退，明确选中片段可能不连续，老师文字不是用户事实/同意，不能重建被省略材料；能解释的先解释，必要澄清仍服从原预算和用户停止边界。schema 1 不变，新增上下文标记可选，旧快照仍可回放。
- 片段行提供独立原生全文展开，选取按钮与展开按钮不嵌套；统一 14pt 内边距，正文完整换行，至少 44pt 控制，大辅助字号下操作纵排。全文仍保留于原交流记录。

### 首轮实际界面

四项 UI **3 通过 / 1 失败**，见[原摘要](evidence/ui-initial-summary.json)。十种目录相关选择和可控边界说明、换位理解说明、原选择页发送均通过，覆盖普通浅色和最大辅助字号深色。16 张导出截图在三张联系表中审读，见[范围](evidence/ui-initial-review.json)。选项完整换行，普通说明目的/条件/示例/边界清楚，最大字号滚动阅读，按钮文字保持对比，推荐操作纵排。

### 长原话布局修正

第二轮退出 65，Xcode 报 `Failed to construct test run summaries ... ioError`，摘要为 unknown/0；不记作通过或可靠测试计数。实际运行截图暴露最大字号下超长历史原话撑出大片空白、滚动定位失稳，见[截图](evidence/ui-long-original-blank.png)。后续改为超 900 字原话默认展示 180 字摘要，明确“查看原话全文”入口；全文在独立原生阅读页按 900 字布局块懒加载，每个字符仍保留，关闭回到交流。普通短原话保持直接展示。未改变持久化和请求中的原始内容。

这是由实际失败发现的交互修正；最后一轮仅重验全文阅读、返回、片段选择、当前输入校验与发送，并在同一固定模拟器检查浅色普通字号、深色最大辅助字号。未重跑已通过的透镜设计测试或增加一般视觉打磨。
