# Mentor 试用观测验收 · 2026-10-03

## 本轮范围

补齐 F18 的技术观测：入口尝试、实际路径切换、首份内容呈现、请求终态和耗时、退出阶段与动作、反馈。原先空白退出、快速切换入口、迟到请求、只读历史及本地保存重试可能导致归属或统计失真；本轮以独立 attempt / request 账本和串行事件队列处理。

- 入口先记录尝试，成功进入才激活；失败或取消保留其入口记录。空白退出不创建业务会话，首次物化材料后关联原尝试。
- 请求携带原尝试和会话归属，成功落盘终态后记录一次；迟到回调不能归到后来入口。只读查询请求终态以核对导航后的结果，不读取私人请求上下文。
- 请求耗时止于传输返回、抛错、取消或超时，本地提交重试的用户等待不增加原请求耗时。
- 每次尝试区分 first_content 与后续呈现、新呈现与 revisit；领域呈现回执重试保留第一次实际观察时间。历史复看只写观测，不补写领域回执或改变生命周期。
- 初始入口固定，实际路径变化单独记录 switched_entry；退出记录离开前阶段与动作，并按尝试去重。
- key 与 value 都进行白名单和类型验证；固定枚举、布尔值、非负整数耗时及受控版本值才允许写入。合法 key 中夹带私人正文同样拒绝。

观测不保存原话、模型正文、API Key 或私人获益说明。反馈未填写保留 unknown。写入为 best effort，失败不阻止业务；删除与写入失败会造成缺失，日志不能作为所有使用的完整分母。汇总口径见[系统设计](../../mingsi-mentor-m1-system-design.md#121-试用观测的实现边界)和[真实试用模板](../../mingsi-mentor-m1-trial.md)。
