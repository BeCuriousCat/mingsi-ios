## 四、安装前优先顺序

1. 修复建议卡到详情的真实路径、实际首页触达、假保存提示，以及回顾相关性和记录去重；用真实页面流程验收。
2. 完成正式教材审核及内容包；如先发有限试用版，必须明确听讲不可用，不能宣称完整 M1。
3. 对拟安装的同一版本跑适用回归、旧库升级及导出 / 删除 / 恢复检查，固定版本和构建号。
4. 在连接并可用的真实 iPhone 上安装，验证语音、系统快捷入口、冷启动与后台恢复，再交付可试用版本；真实试用随后开始。

云同步、账号、团队协作、内容市场等在当前 PRD 中明确延期；前一轮重置提案的四 Tab 不是当前 M1 要求（M1 明确保留五 Tab）。这些不列为本次手机安装的必须补完项。生活建议的系统通知亦应与 App 内每日默认卡片分开，未完成通知不应被拿来掩盖卡片主路径未完成。
