## 已发现并处理的输入问题

实际UI基线1项失败：输入文字后点“完成”，直接回到首页，未显示保留或丢弃选择。截图已人工工具打开、AI审读，输入区域与麦克风本身有留白；问题是关闭行为把未保存内容静默丢失，不是输入入口缺失。

修订将“完成”改为“关闭”，未保存文字、正在录音或待确认的识别会触发系统丢弃确认，用户可继续编辑。空输入和已保存状态直接关闭；录音准备/录音/转写/待确认由共享输入组件向外报告是否有未处理输入。保存期间禁用输入和关闭，成功后只清除与保存快照仍相同的文字，避免异步保存覆盖后来内容。未新增自动云端保存或跨重启草稿存储。
