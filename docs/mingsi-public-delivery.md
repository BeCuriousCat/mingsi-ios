# 明思普通用户安装与首轮分发准备

日期：2026-10-23。状态：**准备中，没有TestFlight/App Store下载链接、签名候选包或真实安装结果。** 对应[长期Goal](mingsi-long-term-goal.md)G9/G10；源码公开不等于普通用户已经能够安装。

## 采用哪条路径

| 路径 | 适用人群与条件 | 本期用途及当前状态 |
| --- | --- | --- |
| Xcode源码构建 | 有Mac/Xcode、愿意配置自己的签名团队；在线模型用自己的服务 | 维护者和其他构建者验证，当前可查看源码；维护者真机签名仍缺账户/描述文件 |
| TestFlight外部测试 | 发布者具备Apple Developer Program与App Store Connect权限；首个外部构建需Apple审核，测试者用iPhone上的TestFlight安装 | 优先用于3–5人试用和G9实际安装，尚未创建或发布 |
| App Store | 完成商店元数据、隐私信息、审核与发布 | 面向更广泛用户的后续公开渠道，当前未提交、无上架日期承诺 |

依据2026-10-23实际读取的[Apple TestFlight说明](https://developer.apple.com/testflight/)、[TestFlight概览](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/)及[开发者计划注册](https://developer.apple.com/programs/enroll/)：开发者计划标价每会员年99美元，地区价格以注册页实际显示为准；TestFlight单个构建最多测试90天。此处没有购买或注册任何服务。试用登记要记录构建到期日，不能把到期无法打开当成用户不愿复用。

## 分发前的具体工作

1. 在拥有者设备保留旧记录与Keychain，解决[当前签名条件](mingsi-phone-acceptance.md)，实际通过P01–P12适用路径。已安装旧App的版本号不能证明它就是候选源码。
2. 固定候选提交、版本/构建号、Prompt和教材版本，绑定远端构建与测试结果、已知限制及升级记录。每个实际上传构建使用可区分的构建号；当前版本号仍是0.1.0(1)，不能用它唯一识别多个历史安装；[源码构建标记](mingsi-build-identity.md)已准备，实际包和手机状态另需核对，不替代上传时递增构建号。
3. 在账户就绪后创建真实App Store Connect记录和签名归档；上传前复查包内资源、权限说明和隐私信息。Apple账户、联系人、团队、隐私表与审核在线体验方案均尚未落实，不代填身份或承诺审核通过。
4. 准备Beta说明、测试重点、反馈联系地址与真实截图。离线阅读可直接体验；在线请求需要有效服务。审核在线体验方案必须实际可用，且不将作者Key、CC Switch订阅或个人网关凭据写进源码/安装包。
5. 候选可审核并具备明确发布授权后再上传、提交审核和分配外部测试构建。没有擅自发出试用邀请；邀请对象和联系行为由拥有者明确授权。
6. 由3位未参与开发的目标用户按同一份说明安装，记录失败和实际协助；至少2人无需开发者实时操作设备。完成首次离线阅读、配置自己的服务、一次在线交流和再次打开，才登记安装成功。

安装说明应先讲清iOS26+、当前Beta身份、是否需要Mac、在线模型的配置与额度、数据保存位置以及如何反馈。先让测试者自然操作；帮助过的位置如实记录，不替他们操作后记成独立成功。

## 当前包配置与仍缺的证据

App自身使用UserDefaults保存快捷请求/偏好，以及`ProcessInfo.systemUptime`计算会话/请求耗时。GRDB已有独立隐私清单，不能代替App声明自身API用途。已准备App清单：UserDefaults为`CA92.1`，事件间计时为`35F9.1`；仅声明已核对用途，不声称在线模型没有数据外传。

日历读取使用`requestFullAccessToEvents`，已准备将旧说明键换为`NSCalendarsFullAccessUsageDescription`，并在构建后读取真实App包验证。语法、plist与工程配置检查不等于授权弹窗已经实际操作，完整构建/测试及真机授权仍待验收。

生活奇遇原先缺少HealthKit entitlement，现已准备[可选健康能力配置](qa/2026-10-23-healthkit-capability/README.md)并用实际轻量模拟器产物核对；明思完整候选、真机签名和读取仍待验收。权限未知/仅写入的表达及请求反馈已通过[隔离原生UI验证](qa/2026-10-23-permission-states/README.md)。需用支持此能力的有效团队和描述文件签名；entitlement只允许请求授权，不代表用户已经授予读取。

在线输入会直接发给用户选定的模型服务，系统语音可能使用联网识别。商店隐私披露还需核对实际服务、保留政策和审核配置；本次required-reason清单不能替代商店隐私表或完整数据流核对。

升级前可通过现有导出保留记录，导出可能含私人原文，但不含API Key。已有特定旧库迁移的备份/失败恢复逻辑；未验证任意新旧版本降级、完整JSON导回或手机重装恢复。因此不承诺删除重装能恢复记录。升级遇到签名变化、数据异常或需要卸载时先保留现场，按[手机准备说明](mingsi-phone-acceptance.md)处理。
