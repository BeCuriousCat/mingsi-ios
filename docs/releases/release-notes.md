# 发布说明

### 2026-10-25

- 导师网络导出增加不使用API Key的配置指纹；离线对账按配置分别统计耗时，切换服务或模型后分别保留，旧记录的配置保持未知。

### 2026-10-24

- 修正本机导出将数字误转为布尔值的问题，保留原始数值和二进制内容；以前导出的文件需从原数据库重新导出才能恢复正确数字。
- 导师网络观测增加正文解析、界面可见、传输结束和正式保存的独立时点；未观察到的阶段保留为空，不用总耗时冒充首字时间。
- 本机导出可保留导师服务自报的数字用量，包括收到用量后的失败请求；缺失、空报告或冲突保持未知，不把它当作实际账单。
- 导师请求向已知协议声明单次输出预算；服务不接受时明确失败，不去掉预算偷偷重发。兼容服务仍需验证支持情况，预算不等于费用上限。
- 本机导出增加导师网络观测，区分系统报告的交易次数与尚未收到的指标；记录随交流删除，不包含正文或凭据。
- 导师回复成功保存后，已发送文字从输入框移入交流记录，方便直接补充下一轮；等待期间新写的草稿继续保留，回复保存失败时也保留原输入。
- 交流输入和发送操作固定在页面底部，随系统键盘避让；回复、来源和可选反馈可以继续滚动阅读。
- 发送后显示等待状态和首段生成正文，新回复保存后定位到回复内容。
- 校对语音转写时，滚动输入区会收起键盘，便于找到确认追加操作。
- 打开本机记录遇到另一项短暂保存时，会短暂等待；持续占用仍报告打开失败，保留已有记录。

### 2026-10-23

- 辅助字号下，版本信息和权限操作改为纵向排列，减少文字挤压。
- 补齐可选健康连接的应用能力配置；健康数据仍由你逐项授权，核心功能不要求健康数据。
- 设置可查看并复制构建信息，区分未标记来源和本地修改；手机安装前核对候选标记与应用身份，避免误认旧版本。
- 系统情境权限区分日历仅写入与健康读取范围未知；授权选择显示等待、拒绝或失败反馈，可在系统设置查看和调整。
- 修正生活奇遇的日历授权说明，适配当前系统的日历读取请求。
- 点拨问题与回答按顺序保存，避免旧草稿覆盖已生成内容；在等待保存期间取消后不再继续请求模型。
- 流式连接意外结束或服务返回错误时不再误报完成；区分可识别的额度、频率、输出上限等问题，提示下一步，隐藏服务端和系统诊断原文。
- 修复App已运行时主屏“记录闪念”只返回原页面的问题，从设置可直接进入闪念并保留草稿；处理完成的快捷请求不再留到下次启动。
- 关闭闪念时，未保存文字、正在录音和待确认转写会先提示继续编辑或明确丢弃；保存期间避免关闭与覆盖新输入。
- 闪念弹窗继承页面字号设置，辅助字号下也能继续输入、检查转写并保存。
- 闪念文字和待确认转写保留为本机草稿，重新打开或重启后可继续；关闭时可以保留草稿，也可明确丢弃。
- 语音输入退到后台时停止录音，保留已识别的文字供检查；草稿存储失败可重试，不显示为已保留。
