# 发布说明

### 2026-09-15

- 首页新增“查看全部交流”，独立列表分页查看历史；从详情返回保留浏览位置，删除记录后刷新附近内容。
- 历史详情支持确认删除一组理解的全部版本及相关派生回应，保留交流原话和其他理解；删除后刷新详情，失败时可重试。
- 历史交流详情可确认删除整段交流；取消时保留，删除失败时留在原页重试，成功后刷新最近交流。
- 点开最近交流先查看历史内容，已结束的交流不会自动恢复；选择“继续这件事”后再编辑或发送。
- “继续这次交流”会找到最近一条有内容的未结束交流，即使它已不在首页最近三条记录中；结束后刷新会移除该恢复目标。
- 导师首页与交流页完成首轮接入：可以从一件事开始，保留交流草稿，写下并确认自己的理解，再回来继续。原来的“今日整理”和五个 Tab 继续保留。
- 未配置模型时，发送前提示打开设置并保留输入。正式教材内容、完整等待超时及部分交流管理操作仍在开发，本次不是导师 M1 的完整交付。

- Today 升级为“今日概览”：同一天可确认和推进多件事项，任意时刻只训练一件，切换前保存并隔离卡片、问题、Quest 和 AI 上下文。
- 整理协议升级为 `MINGSI_STREAM_V2`，复用一次整理调用提出事项分组，并继续兼容旧 V1 输出。
- 到期验证支持非阻塞暂缓；验证、Quest 状态和成长结算事务化保存，单次结算只展示新增证据，不展示分数涨跌。
- History 按事项显示证据链；Growth 回链优先定位事项；Project 支持直接结束、必填结果复盘和保留复盘的状态恢复。
- 内置版本化 GuidanceCatalog 和教练反馈记录；本地规则只筛选客观可用候选，最终提示选择和验证证据判断由中央 LLM 完成。
- 新增 v33-v35 数据迁移、迁移前备份、事项归属约束和 vNext 数据导出。
- Provider Profile Foundation 已延后到 vNext 实现验收和 3-7 天真实体验之后。

### 2026-07-14

- 今日训练收敛为“讲清今天、找出判断、行动验证”三个用户可见阶段；术语入口解释卡片、问题、验证和原则分别代表什么。
- 生成过程提供请求、连接、收到模型数据和持续接收的真实状态，可随时取消并保留当前内容重试；长连接在短暂切到后台时尽力继续，遇到系统中断会给出明确原因。
- 教练先引导用户作答，再提供基于当前材料的对照写法，帮助把事实、判断和可观察验证信号连起来。
- 昨日验证必须记录一条真实结果，并将该证据保存到验证、历史、项目和成长链路；完成任务本身不再被当作判断正确的证明。
- 历史、项目和成长页面优先展示最关键的证据和下一步，搜索、筛选和详情按需展开，降低文字堆叠。
- 模型设置支持保存多个 OpenAI 兼容配置并在 GPT、GLM 等模型之间切换，保留历史配置供后续选择。
