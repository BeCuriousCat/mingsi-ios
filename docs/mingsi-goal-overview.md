# 明思总目标：价值、指标与完成边界

更新：2026-10-24。系统 Goal：**active，未完成**。本页是阅读入口；统计口径和全部通过线以[长期 Goal 与验收契约](mingsi-long-term-goal.md)的 G1–G10 为准，不另设一套评分。

## 目标

**让明思成为可信、低负担的日常思考导师，帮助人在真实生活中观察得更准确、表达得更清楚、判断得更有依据，并在下一次遇到问题时能够独立运用。**

本期可结束的交付是：首个经过真实使用、至少四周后续复用和普通用户安装验证的开源版本。透镜、Prompt、语音、流式回复、人生指南与历史回看都应服务于这个目标。

核心价值指标：每周全部真实尝试中，有多少次用户能具体说明帮助，以及多少次后来在另一事件中独立复用。并列保留未获益、退出、未反馈及反馈覆盖率。测试数、使用时长与新增功能数不计作实际获益。

## 达到什么才算完成

| 门槛 | 本期通过线摘要 | 当前缺口 |
| --- | --- | --- |
| G1 可信与数据 | 适用功能验收均有证据；已承诺输入静默丢失、来源串线、虚构经历、失败伪装成功、密钥泄露均无未解决问题 | 部分工程证据已有；真机语音、强退、VoiceOver仍需验证 |
| G2 低负担入口 | 前至少10次真实尝试至少8次无需先整理长材料，覆盖至少5次无准备；拥有者窗口至少12次、6次无准备；无Key等边界可离线开始和结束 | 真实试用分母未建立 |
| G3 网络可靠 | 同一候选及明确支持的服务配置，至少7天、50次预登记请求至少48次完整可用，含10段两轮以上交流；10秒内有等待反馈，取消和失败可辨；报告首份可读正文与完整回复p50/p95 | 正式窗口未开始；服务合同、用量及分阶段计时仍缺 |
| G4 自用具体价值 | 拥有者约14天、至少12次尝试；带题与导师供题各至少4次、各至少3个由本人说明的具体获益案例 | 尚无符合口径的真人报告 |
| G5 他人重复价值 | 3–5人各约14天、各至少6次自然尝试，两类主路径各至少2次；至少3人各有2个不同日期获益案例，并主动回来一次且能说明原因 | 未开展外部试用 |
| G6 独立复用 | 至少3人、6个独立复用案例、2类现实情境；每人观察至少4周 | 未验证；AI演练不计入 |
| G7 比普通聊天有帮助 | 相同模型配置、同材料与相当上下文，20组匿名随机顺序比较，每组至少3位真人判断；至少14组不差、其中至少8组更有帮助，明显更差不超过2组 | 比较协议已准备，真人盲评未开始 |
| G8 自主与负担 | 明确拒绝/停止均尊重；无未解决强迫训练、虚构成长或停止后追问；至少80%反馈认为负担可接受，反馈至少20条且覆盖一半尝试 | 合成边界仅是前置证据；真人负担未知 |
| G9 可实际安装 | 有经授权的签名分发渠道；3位非开发参与者在自己iPhone完成安装、配置、首次离线阅读与在线交流，至少2人无需开发者实时操作设备 | 签名分发和3人安装未通过 |
| G10 可开源维护 | 许可、归属、隐私合格；干净环境完成Release和免费测试；发布绑定验收、升级、导出、恢复与限制；至少1名其他构建者走通 | CI已有工程证据；其他构建者和正式发布验收仍缺 |

这些数字是本期早期产品决策线，不是统计研究结论。十项分别通过且产品拥有者确认本期结论，才可标记完成；不计算能相互抵消的总分。失败、缺样本或外部依赖保留原状态，不通过降低门槛结项。

## 本期边界

- 面向愿意自配模型的iOS 26+个人用户，先验证自用，再验证相近用户。
- 用户保留决定、休息和退出的权利；不做专业诊断或保证判断正确，不凭一句话评价人格与能力。
- 人生指南维持每日资料入口与场景相关可选卡片；不增加索取随机建议任务、强制打卡、成长总分、作业配额或排行榜。
- 暂不扩展账号云同步、社交、团队、商业化、无限资讯流或跨平台重写；Pi等框架只有出现明确任务需要时再评估。
- 私人原文和Key不公开、不随开源分发；默认不新增外部遥测。不擅自联系试用者、发布分发渠道或扩大付费测试。

后续每次汇报固定说明：推进哪个G指标、解决什么障碍、新增什么证据、距离通过还缺什么。只有出现真实数据才报告价值变化；本页和详细契约不代表任何人已经获得帮助。
